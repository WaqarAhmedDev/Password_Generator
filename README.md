# React Password Generator

A secure and customizable password generator built with React that creates strong passwords based on user preferences.

## Features

- Adjustable password length (6-100 characters)
- Option to include numbers
- Option to include special characters
- Real-time password generation
- Copy to clipboard functionality
- Responsive design

## Technologies Used

- React (Functional Components with Hooks)
- CSS3 (Modern UI with responsive design)
- JavaScript (ES6+ with secure random generation)

## How to Use

- Use the slider to select password length (6-100 characters)

- Check the "Include Numbers" box to add digits to your password

- Check the "Include Special Characters" box to add symbols

- Click "Generate Password" to create a new password

- Click the copy icon to copy the password to clipboard
